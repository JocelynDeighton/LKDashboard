# Labs & Kits Dashboard

A materials overview for K-12 labs and kits. The project is at its repository and scope-discovery baseline; it does not yet load inventory or calculate quantities.

## Quick Start

Open `index.html` in a modern browser. No install or build step is required.

## Current State

The baseline intentionally shows that no verified workbook is connected. It does not contain sample inventory, assume missing stock is zero, or calculate material requirements. Workbook structure and quantity rules must be reviewed before those behaviors are specified.

See [`planning/`](planning/) for the Phase 1–2 plan, product scope, decisions, and risks. Local Excel and CSV files under `data/` are excluded from Git by default.
